目前只有切换到某个工作区时才恢复它缺的窗口。这次重启后有 7 个 Chrome 窗口和 1 个 VS Code 窗口（StockViewer）一直没恢复。

做法：开机后等登录项应用稳定（约 20–30 秒或新窗口不再出现），统一识别一遍，再在后台逐个恢复缺失窗口：先当前工作区，再其他工作区，彼此间隔，避免一次开出一堆窗口。

## 验收标准
- [ ] 重启后不点任何工作区，缺失窗口也会在后台恢复
- [ ] 恢复过程不打断当前前台窗口
- [ ] Chrome 按网址、VS Code 按项目文件夹恢复成功
