有些应用可以把自己收到屏幕侧边，从侧边弹出一个面板。面板移到侧边或弹出时，TabStack 把它当成焦点变化处理（`didActivateApplicationNotification` / `kAXFocusedWindowChangedNotification` → `handleFocus` → `applyFocus` → `followFocus`，之后还有 `recheckFocus`），结果把这个应用原本的窗口显示或置前。

怀疑点（待复现验证）：
- `applyFocus` 只要求焦点窗口有 window id，不看是否标准窗口；
- `activation` 分支（⌘Tab / Dock 带出上次用的窗口）只要当前工作区有该应用的标签就 `select(tab)`；
- 未绑定标签那一支可能把面板绑成标签；
- `followFocus` 可能因此切换工作区。

## 验收标准
- [ ] 复现并用日志确认是哪一步把原窗口拉出来
- [ ] 弹出 / 收起侧边面板时，应用原窗口不出现，工作区不切换，高亮不变
- [ ] ⌘Tab、点 Dock 仍会显示当前工作区里该应用的窗口
- [ ] 焦点跟随（焦点落到别的工作区的窗口 0.4 秒后切过去）照常
- [ ] 用 `build.sh` 编译并在真机验证；不影响 T-0014 未提交的改动
