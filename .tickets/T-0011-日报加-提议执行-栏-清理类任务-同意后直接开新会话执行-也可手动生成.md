用户想在日报里看到“提议执行的任务”，主要用来清理任务：已完成却没关的工单、重复工单、长期没动的工单、已合并可删的分支、没提交的改动等。用户同意后直接开新的 Claude Code 会话去做；也可以自己随时触发生成。

新会话用 Claude 桌面版的 `claude://code/new?q=<任务说明>&folder=<项目目录>`：会把说明填进新会话的输入框，用户按回车才开始（不会自动发送）。

## 验收标准
- [ ] TicketDeck 日报 JSON 有 `proposals`，`ticketdeck report annotate --proposal` 可写入，终端版日报也显示
- [ ] 每天 8 点的定时任务会生成最多 5 条提议
- [ ] ⌃⌥T 今日计划里有「提议执行」栏：「执行」在对应项目开新会话并填好说明，「忽略」隐藏该条
- [ ] 面板上可手动「生成提议」，生成后面板自动刷新
