# TabStack

一个贴在屏幕左侧的窗口侧边栏，可以把常用窗口分成多个**工作区**，像 Chrome 的竖向标签一样一键切换。每个标签对应一个具体窗口，同一个应用（比如 Chrome）的多个窗口可以各占一个标签。

## 原理

macOS 不允许把其他应用的窗口嵌进自己的窗口，所以 TabStack 采用“侧边栏加窗口调度”的方式：

- 侧边栏是一个贴在主屏幕左边的悬浮面板，所有桌面都显示，点击它不会抢走焦点。
- 切换标签时，用辅助功能 API（AXUIElement）把标签对应的那个窗口铺满屏幕剩余区域（去掉菜单栏、Dock 和侧边栏）并置顶，同时隐藏同一工作区里的其他应用。
- 切换工作区时，隐藏旧工作区的应用，再恢复新工作区上次选中的标签。

## 构建与运行

```bash
./build.sh
open build/TabStack.app
```

首次运行需要在 **系统设置 → 隐私与安全性 → 辅助功能** 里允许 TabStack。
默认使用 ad-hoc 签名，每次重新构建后可能需要重新授权；设置 `SIGN_IDENTITY` 为一个固定证书可避免：

```bash
SIGN_IDENTITY="Apple Development: you@example.com" ./build.sh
```

TabStack 不显示 Dock 图标和菜单栏，退出入口在侧边栏顶部的工作区菜单里。

## 使用

| 操作 | 方式 |
|---|---|
| 切换标签 | 点击侧边栏图标，或 `⌥⌘1`…`⌥⌘9` |
| 切换工作区 | 点击顶部工作区图标选择，或 `⌃⌥1`…`⌃⌥9`（侧边栏显示的那几个） |
| 搜索工作区 | `⌃⌥F`：输入名字或窗口标题，↑↓ 选择、↩ 打开；不输入时按推荐排序，包括已收起的工作区 |
| 关闭窗口 | `⌃⌥D`：关闭当前窗口并从列表移除，然后切到相邻的窗口 |
| 上一个 / 下一个标签 | `⌃⌥↑` / `⌃⌥↓`（当前工作区内循环） |
| 上一个 / 下一个工作区 | `⌃⌥←` / `⌃⌥→`（循环） |
| 显示 / 隐藏侧边栏 | `⌥⌘0`（隐藏后当前应用会铺满屏幕） |
| 添加窗口 | 点击 `＋`：“新建窗口”可直接为 Finder（自动打开“前往文件夹”）、终端、iTerm、Safari、Chrome / Edge / Brave（可选账号）开一个新窗口；“已打开的窗口”按应用列出现有窗口；也可以从“应用程序”文件夹选择应用 |
| 调整顺序 | 在侧边栏按住图标上下拖动 |
| 管理工作区 | “工作区设置”窗口（工作区菜单或菜单栏图标 → 工作区设置…，⌘,）：拖动排序工作区和窗口、改名、选颜色、移动窗口到其他工作区、添加或移除窗口 |
| 管理标签 | 右键图标：重命名、绑定到当前窗口、上移、下移、退出应用、从工作区移除 |

其他行为：

- 用 ⌘Tab 或 Dock 切到当前工作区里的应用时，侧边栏高亮同步，窗口自动铺满内容区。
- 用快捷键切换时，屏幕中间会短暂显示切到的应用或工作区。
- 有应用全屏时侧边栏自动隐藏，回到桌面后恢复。
- 显示 Dock 上的未读角标。
- 工作区和标签自动保存；退出 TabStack 时会恢复所有被隐藏的应用。
- 同一个应用有多个标签时，图标下方会显示窗口标题（或你起的名字）。
- 在应用内直接点另一个已加入的窗口，侧边栏高亮也会跟着切换。
- **重启后恢复**：TabStack 会记住每个窗口怎么重新打开——VS Code / Cursor 记项目文件夹，Chrome / Edge / Brave 记窗口里所有标签页网址（首次需允许 TabStack 控制浏览器），文档窗口记文件。重启后先认回应用自己恢复的窗口，真正缺失的再重新打开：点标签恢复单个窗口，切换工作区时自动恢复整组（可在设置里关闭），也可以用“恢复本工作区窗口”。
- 同一个窗口可以同时出现在多个工作区里。
- **只显示常用的工作区**：侧边栏默认最多显示 5 个（设置里可改），由当前工作区、固定的工作区和推荐分最高的组成。推荐用 frecency：每次切换和每停留 10 分钟各计一分，分数每 3 天减半。其余工作区不会删除，只是收起，用 `⌃⌥F` 或工作区菜单里的“其他工作区”打开。

## 让 AI 配置工作区（MCP）

`build/TabStack.app/Contents/MacOS/tabstack-mcp` 是一个 MCP 服务器（stdio），Claude Code 等助手可以用它直接为项目搭好工作区。它通过 TabStack 的本地控制通道（`~/Library/Application Support/TabStack/control.sock`，仅当前用户可读写）操作正在运行的 TabStack；TabStack 没开时会先启动它。

在 Claude Code 里注册（所有项目可用）：

```bash
claude mcp add --scope user tabstack -- ~/projects/TabStack/build/TabStack.app/Contents/MacOS/tabstack-mcp
```

工具：

| 工具 | 作用 |
|---|---|
| `list_workspaces` | 所有工作区及其窗口：是否打开、怎么恢复（文件夹 / 网址 / 文件）、是否显示在侧边栏、是否固定 |
| `list_windows` | 当前打开的窗口（按应用分组，含 windowID、已在哪些工作区） |
| `list_browser_profiles` | Chrome / Edge / Brave 的账号 |
| `create_workspace` / `update_workspace` / `delete_workspace` | 新建、改名、改色、固定、排序、删除工作区 |
| `switch_workspace` | 切换工作区（可指定窗口） |
| `open_window` | 开一个新窗口并加入工作区：VS Code / Cursor 打开文件夹，终端在某目录打开，Finder 打开文件夹，浏览器用指定账号打开一组网址 |
| `add_window` | 把已打开的窗口加入工作区 |
| `update_tab` / `remove_tab` | 改名、移到别的工作区、调整顺序；移除（可同时关闭窗口） |
| `restore_workspace` | 重新打开工作区里缺失的窗口 |

例如对助手说：“为 ~/projects/foo 建一个工作区：VS Code 打开项目，终端进到项目目录，Chrome 用 Work 账号打开 localhost:3000 和 GitHub 仓库。”

## 已知限制

- 侧边栏只停靠在主显示器
- 同一应用的其他窗口不能单独隐藏，切换时它们叠在当前窗口后面
- 识别窗口用到了私有 API `_AXUIElementGetWindow`
- 固定尺寸的窗口会居中显示在内容区
- 侧边栏处于悬浮层级，最大化的非工作区窗口不会盖住它
- 因为需要控制其他应用，无法开启沙盒，不能上架 Mac App Store
