# TabStack

一个贴在屏幕左侧的窗口侧边栏，可以把常用窗口分成多个**工作区**，像 Chrome 的竖向标签一样一键切换。每个标签对应一个具体窗口，同一个应用（比如 Chrome）的多个窗口可以各占一个标签。

## 原理

macOS 不允许把其他应用的窗口嵌进自己的窗口，所以 TabStack 采用“侧边栏加窗口调度”的方式：

- 侧边栏是一个贴在主屏幕左边的悬浮面板，所有桌面都显示，点击它不会抢走焦点。
- 切换标签时，用辅助功能 API（AXUIElement）把标签对应的那个窗口铺满屏幕剩余区域（去掉菜单栏、Dock 和侧边栏）并置顶，同时隐藏同一工作区里的其他应用。
- 切换工作区时，隐藏旧工作区的应用，再恢复新工作区上次选中的标签。

## 构建与运行

```bash
./build.sh
open build/TabStack.app
```

首次运行需要在 **系统设置 → 隐私与安全性 → 辅助功能** 里允许 TabStack。
默认使用 ad-hoc 签名，每次重新构建后可能需要重新授权；设置 `SIGN_IDENTITY` 为一个固定证书可避免：

```bash
SIGN_IDENTITY="Apple Development: you@example.com" ./build.sh
```

TabStack 不显示 Dock 图标和菜单栏，退出入口在侧边栏顶部的工作区菜单里。

## 使用

| 操作 | 方式 |
|---|---|
| 切换标签 | 点击侧边栏图标，或 `⌥⌘1`…`⌥⌘9` |
| 切换工作区 | 点击顶部工作区图标选择，或 `⌃⌥1`…`⌃⌥9` |
| 上一个 / 下一个标签 | `⌃⌥↑` / `⌃⌥↓`（当前工作区内循环） |
| 上一个 / 下一个工作区 | `⌃⌥←` / `⌃⌥→`（循环） |
| 显示 / 隐藏侧边栏 | `⌥⌘0`（隐藏后当前应用会铺满屏幕） |
| 添加窗口 | 点击 `＋`，按应用分组列出所有窗口，选一个即可；也可以从“应用程序”文件夹选择应用 |
| 管理工作区 | 工作区菜单：新建、重命名、排序、删除、启动全部应用 |
| 管理标签 | 右键图标：重命名、绑定到当前窗口、上移、下移、退出应用、从工作区移除 |

其他行为：

- 用 ⌘Tab 或 Dock 切到当前工作区里的应用时，侧边栏高亮同步，窗口自动铺满内容区。
- 用快捷键切换时，屏幕中间会短暂显示切到的应用或工作区。
- 有应用全屏时侧边栏自动隐藏，回到桌面后恢复。
- 显示 Dock 上的未读角标。
- 工作区和标签自动保存；退出 TabStack 时会恢复所有被隐藏的应用。
- 同一个应用有多个标签时，图标下方会显示窗口标题（或你起的名字）。
- 在应用内直接点另一个已加入的窗口，侧边栏高亮也会跟着切换。
- 窗口关闭或应用重启后，标签会变灰；再次点击时会按原标题或空闲窗口自动重新绑定。
- 同一个窗口可以同时出现在多个工作区里。

## 已知限制

- 侧边栏只停靠在主显示器
- 同一应用的其他窗口不能单独隐藏，切换时它们叠在当前窗口后面
- 识别窗口用到了私有 API `_AXUIElementGetWindow`
- 固定尺寸的窗口会居中显示在内容区
- 侧边栏处于悬浮层级，最大化的非工作区窗口不会盖住它
- 因为需要控制其他应用，无法开启沙盒，不能上架 Mac App Store
